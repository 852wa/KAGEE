Kagee - 3D stage & cinematic effects for OBS Studio
https://github.com/852wa/KAGEE

■ 必要なもの
  Windows 10 / 11 (64bit)、OBS Studio 32.2 以降

■ インストール
  1. OBS Studio を終了します。
  2. install.bat をダブルクリックします。
     （「WindowsによってPCが保護されました」と出た場合は「詳細情報」→「実行」）
  3. OBS Studio を起動し、メニュー「ドック」→「Kagee」でパネルを表示します。

■ 使い方（最短）
  1. 3Dにしたいシーンの一番上に「Kagee 3Dステージ」を追加します（ソース → ＋）。
  2. パネルの「このシーンのアイテムをレイヤーとして取り込む」を押します。
  3. 「おまかせで8ショット作成」を押し、番号ボタンでショットを切り替えます。

■ アンインストール
  OBS Studio を終了してから uninstall.bat をダブルクリックします。

----------------------------------------------------------------------
■ Requirements
  Windows 10 / 11 (64-bit), OBS Studio 32.2 or later

■ Install
  1. Close OBS Studio.
  2. Double-click install.bat
     (if Windows SmartScreen appears: "More info" -> "Run anyway").
  3. Start OBS Studio and open the panel: Docks -> Kagee.

■ Quick start
  1. Add "Kagee 3D Stage" at the TOP of the scene you want in 3D (Sources -> +).
  2. In the panel, press "Import this scene's items as layers".
  3. Press "Create 8 varied shots automatically" and switch shots with the number buttons.

■ Uninstall
  Close OBS Studio, then double-click uninstall.bat.
